# VPN Protocol

Небольшой vpn протокол на python

Сейчас это локальный HTTP proxy, который гоняет трафик через зашифрованный tcp туннель

## Как работает

Туннель разворачивается, слушая локальный порт 9003 (можете поменять в коде)

Далее ваши программы отправляют трафик на этот порт

Оттуда он попадает в vpn protocol, шифруется и отправляется на выходной узел

При подключении клиент и сервер обмениваются публичными ключами, проходят аутентификацию через VPN_SECRET и создают сессионные ключи

После этого данные шифруются через `XChaCha20-Poly1305` и передаются фреймами (батчами)

## Установка

На клиенте и на сервере клонируете репозиторий, заходите в папку, далее

    python -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt

## Настройка

Заполняете `.env` файл

VPN_SECRET должен быть и на клиенте, и на сервере одинаковым, его можно сгенерировать через:

    python -c "import secrets; print(secrets.token_hex(32))"

## Запуск

Сервер:

    python -m server.main

Клиент:

    python -m client.main

После запуска клиент слушает:

`127.0.0.1:9003`

Проверка:

curl --proxy http://127.0.0.1:9003 https://example.com/

## Структура

`protocol/` - framing, authentication, обмен ключами, шифрование и состояния

`client/` - локальный прокси и соединение с сервером

`server/` - обработка клиентов и соединение с target

С безопасностью тут вроде бы всё неплохо, но это тестовый проект, и лучше использовать нормальные протоколы, которые будут быстрее и лучше.
